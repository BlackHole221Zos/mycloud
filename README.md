```markdown
# MyCloud — Личное облачное хранилище

## Основные возможности
- Регистрация и вход
- Загрузка, скачивание, удаление файлов и папок
- Корзина с восстановлением
- Массовые операции (выделение, удаление, восстановление)
- Создание папок и навигация по ним
- Современный адаптивный интерфейс (отлично работает на телефоне)
- Админ-панель — просмотр всех пользователей и их файлов
- Прогресс-бар использования хранилища
- Скачивание папок как ZIP
- Поддержка русских имён файлов


## Установка и запуск
git clone https://github.com/ BlackHole221Zos/mycloud.git
cd mycloud

# Создаём виртуальное окружение
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# Устанавливаем зависимости
pip install Flask

# Создаём базу данных и админа
python init_db.py

# Запускаем сервер
python app.py
```


## Структура проекта
```
MyCloud/
├── app.py              — запуск приложения
├── init_db.py          — создание БД и админа
├── config.py           — настройки
├── utils.py            — вспомогательные функции
├── uploads/            — загруженные файлы (создаётся автоматически)
├── static/
│   └── style.css       — стили
├── templates/          — HTML-шаблоны
└── routes/
    ├── auth.py         — авторизация
    ├── files.py        — работа с файлами
    ├── admin.py        — админ-панель
    └── bulk.py         — массовые операции
```

## Требования
- Python 3.9+
- Flask
