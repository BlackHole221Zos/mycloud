MyCloud — Личное облачное хранилище

**Основные возможности**  
- Регистрация и вход, восстановление пароля без почты  
- Загрузка (Drag & Drop), скачивание, удаление файлов и папок  
- Создание вложенных папок, перемещение и копирование файлов  
- Группы: совместное хранилище с настраиваемым лимитом (1–50 ГБ)  
- Приглашения в группы по ссылке с ПИН‑кодом и QR‑кодом  
- Корзина с восстановлением (личная и для групп)  
- Массовые операции (выделение, удаление, перемещение, копирование)  
- Современный адаптивный интерфейс (отлично работает на телефоне)  
- Тёмная тема и переключение вида (Список / Плитка)  
- Админ‑панель — просмотр всех пользователей, файлов и выгрузка БД  
- Прогресс‑бар загрузки файлов  
- Скачивание папок как ZIP
- Быстрый предпросмотр изображений, PDF и текстовых/кодовых файлов в модальном окне  
- Встроенный редактор текстовых и кодовых файлов (в личном и групповом хранилище)  
- Прямые ссылки на файлы с паролем, лимитом скачиваний и сроком действия  
- Сохранение файлов по прямым ссылкам сразу в «Мои файлы»

**Установка и запуск**

```bash
git clone https://github.com/BlackHole221Zos/mycloud.git
cd mycloud
```

Создаём виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Устанавливаем зависимости:

```bash
pip install -r requirements.txt
```

Создаём базу данных и админа:

```bash
python init_db.py
```

Запускаем сервер:

```bash
python app.py
```

**Структура проекта**

```text
mycloud/
├── app.py          — точка входа
├── init_db.py      — инициализация БД и админа
├── config.py       — настройки
├── utils.py        — вспомогательные функции
├── routes/         — основные модули маршрутов: auth (логин/регистрация), files (файлы и папки), groups (группы и общее хранилище), admin (админ‑панель), bulk (массовые операции)
├── templates/      — HTML‑шаблоны
├── static/
│   ├── style.css   — основные стили
│   └── js/         — JavaScript (логика файлов, групп, UI)
└── uploads/        — загруженные файлы (создаётся автоматически)

```

**Требования**

- Python 3.10+  
- Flask и зависимости из `requirements.txt`
