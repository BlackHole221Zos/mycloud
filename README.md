MyCloud — Личное облачное хранилище

Основные возможности
- Регистрация и вход
- Загрузка (Drag & Drop), скачивание, удаление файлов и папок
- Создание вложенных папок, перемещение и копирование файлов
- Группы: совместное хранилище с настраиваемым лимитом (1-50 ГБ)
- Приглашения в группы по ссылке с ПИН-кодом и QR-кодом
- Корзина с восстановлением (личная и для групп)
- Массовые операции (выделение, удаление, перемещение)
- Современный адаптивный интерфейс (отлично работает на телефоне)
- Темная тема и переключение вида (Список / Плитка)
- Админ-панель — просмотр всех пользователей, файлов и выгрузка БД
- Прогресс-бар загрузки файлов
- Скачивание папок как ZIP
- Поддержка русских имён файлов


Установка и запуск
```markdown
git clone https://github.com/BlackHole221Zos/mycloud.git
cd mycloud
```
Создаём виртуальное окружение

```Markdown

python -m venv .venv
.venv\Scripts\activate
```
Устанавливаем зависимости

```Markdown

pip install -r requirements.txt
```
Создаём базу данных и админа

```Markdown

python init_db.py
```
Запускаем сервер

```Markdown

python app.py
```
Структура проекта

```Markdown

MyCloud/
├── app.py              — запуск приложения
├── init_db.py          — создание БД и админа
├── config.py           — настройки
├── utils.py            — вспомогательные функции
├── uploads/            — загруженные файлы (создаётся автоматически)
├── static/
│   └── style.css       — стили
├── templates/          — HTML-шаблоны
│   └── groups/         — шаблоны для групп
└── routes/
    ├── auth.py         — авторизация
    ├── files.py        — работа с файлами
    ├── admin.py        — админ-панель
    ├── bulk.py         — массовые операции
    └── groups.py       — логика групп
```
Требования
    Python 3.10+
    Flask
