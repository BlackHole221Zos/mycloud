Простое веб-приложение, реализующее персональное облачное хранилище с поддержкой регистрации, авторизации, загрузки файлов, создания папок и просмотра файловой структуры. Каждый пользователь имеет изолированное пространство для хранения данных. Включает базовую админ-панель для просмотра списка пользователей, их файлы которые они загрузили вместе с расположением этого файла (путём).
